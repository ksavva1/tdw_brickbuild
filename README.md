# TDW Brick Build (Hard Coded)

This repo is a small test project that hardcodes a brick building model in TDW ([ThreeDWorld](https://www.threedworld.org/)).

## Notes
- Use Python 3.11 (not 3.14)
- Need to add settling phase after movements otherwise box will be flung in direction of prior travel
